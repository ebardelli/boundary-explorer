How-To Guide

Select a Map: Use the drop down to select a map.
Select one or more schools
Use the Auto Paint feature (now under Mapping Tools). Open the Mapping Tools panel on the left and expand the Auto Paint subsection. You can use the dropdowns there to adjust the settings.
Select Mode: You can use this mode to fix individual blocks. You will need to click on each block individually. Press the Esc key exits this mode.
Paint Mode: You can use this mode to paint multiple blocks at the same time. Press the Space bar to activate and deactivate this mode.

Guía de Uso

Seleccionar un Mapa: Use el menú desplegable para seleccionar un mapa.
Seleccionar una o más escuelas
Usar la función de Pintura Automática (ahora en Herramientas de Mapeo). Abra el panel de Herramientas de Mapeo a la izquierda y expanda la subsección de Pintura Automática. Puede usar los menús desplegables allí para ajustar la configuración.
Modo de Selección: Puede usar este modo para arreglar bloques individuales. Necesitará hacer clic en cada bloque individualmente. Presione la tecla Esc para salir de este modo.
Modo de Pintura: Puede usar este modo para pintar múltiples bloques al mismo tiempo. Presione la barra Espacio para activar y desactivar este modo.

Mapping Tools

Where to find them: The Mapping Tools panel appears on the left (look for "Mapping Tools" or the mapping-tools placeholder). These controls help you work with external layers and prepare maps for export.

  • Upload Layer — Load a GeoJSON (or supported vector) file as a reference layer (attendance zones, parcels, existing boundaries). Uploaded layers are available only for the current session unless you export your map.
  • Paint By Layer — Use an uploaded layer to paint blocks in bulk based on geometry overlap. Select the uploaded layer and the target school to transfer the layer's coverage onto census blocks.
  • Assign By Neighbors — Automatically fill small unassigned blocks by assigning them the majority school from surrounding blocks. Useful for closing gaps after layer painting.
  • Merge By School — Combines contiguous blocks assigned to the same school into a single polygon per school. Run this before exporting if you want one feature per school rather than many small block polygons.
  • Auto Paint — Auto Paint uses heuristics to assign blocks automatically; open the Auto Paint subsection to access its settings.

Notes: Mapping Tools display status and progress messages inside the Mapping Tools box. Always review the status text after running an operation. If you plan to save or share the results, run "Merge By School" (if desired) and then use Export GeoJSON to save the merged output.

Quick Recipes

Exporting / recommended workflow

If you want a single polygon per school, run Mapping Tools → Merge By School first, then use Export GeoJSON. If you don't merge, export will contain the original block geometries and assignments. Merging can simplify sharing and reduce file size.

Supported upload formats

GeoJSON is recommended. Other vector formats may work if the browser supports them. The app expects data in WGS84 (EPSG:4326) / lon-lat coordinates — if your file uses a projected CRS, convert it first.

Paint By Layer example

1) Mapping Tools → Upload Layer (select GeoJSON). 2) Choose the uploaded layer in Paint By Layer. 3) Choose the target school. 4) Run Paint — review status. 5) Optionally run Assign By Neighbors to fill gaps, then Merge By School, then Export.

Herramientas de Mapeo

Dónde encontrarlas: El panel de Herramientas de Mapeo aparece a la izquierda (busque "Mapping Tools" o el marcador mapping-tools). Estos controles le ayudan a trabajar con capas externas y preparar mapas para exportar.

  • Subir Capa — Cargue un archivo GeoJSON (u otro vector compatible) como capa de referencia (zonas de asistencia, parcelas, límites existentes). Las capas subidas solo permanecen en la sesión actual a menos que exporte su mapa.
  • Pintar por Capa — Use una capa subida para pintar bloques en bloque según la superposición geométrica. Seleccione la capa subida y la escuela destino para transferir la cobertura de la capa a los bloques censales.
  • Asignar por Vecinos — Rellena automáticamente pequeños bloques sin asignar usando la escuela mayoritaria de los bloques circundantes. Útil para cerrar huecos después de pintar con una capa.
  • Fusionar por Escuela — Combina bloques contiguos asignados a la misma escuela en un solo polígono por escuela. Ejecute esto antes de exportar si desea una característica por escuela en lugar de muchos polígonos pequeños.
  • Pintura Automática — La Pintura Automática utiliza heurísticas para asignar bloques automáticamente; abra la subsección para acceder a sus opciones.

Notas: Las Herramientas de Mapeo muestran mensajes de estado y progreso dentro del recuadro de Herramientas de Mapeo. Revise siempre el texto de estado después de ejecutar una operación. Si planea guardar o compartir los resultados, ejecute "Fusionar por Escuela" (si lo desea) y luego use Exportar GeoJSON para guardar la salida fusionada.

Recetas Rápidas

Exportar / flujo recomendado

Si desea un polígono por escuela, ejecute Herramientas de Mapeo → Fusionar por Escuela antes de Exportar GeoJSON. Si no fusiona, la exportación contendrá las geometrías de bloque originales. Fusionar facilita compartir y puede reducir el tamaño del archivo.

Formatos soportados

GeoJSON se recomienda. Otros formatos vectoriales pueden funcionar si el navegador los admite. La aplicación espera datos en WGS84 (EPSG:4326) o coordenadas lon/lat; si su archivo usa un SRC proyectado, conviértalo primero.

Ejemplo Pintar por Capa

1) Herramientas de Mapeo → Subir Capa (seleccione GeoJSON). 2) Seleccione la capa subida en Pintar por Capa. 3) Elija la escuela destino. 4) Ejecute Pintar y revise el estado. 5) Opcionalmente ejecute Asignar por Vecinos para rellenar huecos, luego Fusionar por Escuela y Exportar.

Frequently Asked Questions

How do I erase a school?

Select the Remove from Map button and all blocks colored in for the school will be erased, as will the pin signifying the school's location.

How do I erase a block?

You can't erase a block, you can only Select or Paint over it with another school's color.

How do I save my map?

Select the Export GeoJSON button on the bottom right hand side of the page.

How do I keep working on a map I saved?

Select the Import GeoJSON button on the bottom left hand side of the page to upload your previously saved map (this restores colors and assignments from that file).

If you want to load an external reference layer (for example a zoning or attendance-area GeoJSON) instead of a full saved map, open Mapping Tools and use Upload Layer. Uploaded layers are session-only and are used as references for "Paint By Layer" and other mapping operations.

How were these blocks created?

These are census blocks and they reflect all students currently enrolled in a traditional SRCS school. The student counts do not include our Charter School students or students not attending a SRCS school.

Can I determine how many students live within a particular block?

No, you are only able to see the student count under the statistics information.

How do I drag the map?

You can drag the map when in Paint Mode or when neither Mode button is selected.

How do I start over?

Refresh the page.

How do I know how many students a school can hold?

Select a school, then Select or Paint at least one block, the school's statistics will automatically populate under the Statistics section on the left hand side of the page.

Can I add a Middle School to an Elementary School District Map?

Yes. You can add any school to any map however the map will still only reflect the district boundaries for the base map you originally selected.

Troubleshooting

Upload failed / blank layer

Check that the file is valid GeoJSON and under browser upload limits. Validate with geojson.io or convert with ogr2ogr if needed.

Paint had no effect

Confirm the uploaded layer overlaps the census blocks and that the correct target school is selected. Check the Mapping Tools status text for errors.

Shortcuts

Space — Toggle Paint Mode. Esc — Exit Select Mode. Buttons include ARIA labels for assistive tech; contact the team if you need additional accessibility support.

Support

Questions or bugs? Please open an issue in the repository with the page name and browser/version, or email the maps team with a short description and a copy of the GeoJSON you used.

Preguntas Frecuentes

¿Cómo borro una escuela?

Seleccione el botón Eliminar del Mapa y se borrarán todos los bloques coloreados para la escuela, así como el pin que indica la ubicación de la escuela.

¿Cómo borro un bloque?

No se puede borrar un bloque, solo puede Seleccionar o Pintar sobre él con el color de otra escuela.

¿Cómo guardo mi mapa?

Seleccione el botón Exportar GeoJSON en la parte inferior derecha de la página.

¿Cómo continúo trabajando en un mapa que guardé?

Seleccione el botón Importar GeoJSON en la parte inferior izquierda de la página para cargar su mapa guardado (esto restaura colores y asignaciones desde ese archivo).

Si desea cargar una capa de referencia externa (por ejemplo un GeoJSON de zonificación o de áreas de asistencia) en lugar de un mapa guardado completo, abra Herramientas de Mapeo y use Subir Capa. Las capas subidas solo existen en la sesión y se usan como referencias para "Pintar por Capa" y otras operaciones.

¿Cómo se crearon estos bloques?

Estos son bloques censales y reflejan todos los estudiantes actualmente matriculados en una escuela tradicional SRCS. Los recuentos de estudiantes no incluyen a nuestros estudiantes de Escuelas Charter o estudiantes que no asisten a una escuela SRCS.

¿Puedo determinar cuántos estudiantes viven dentro de un bloque en particular?

No, solo puede ver el recuento de estudiantes en la información de estadísticas.

¿Cómo arrastro el mapa?

Puede arrastrar el mapa cuando está en Modo Pintura o cuando ningún botón de Modo está seleccionado.

¿Cómo empiezo de nuevo?

Actualice la página.

¿Cómo sé cuántos estudiantes puede albergar una escuela?

Seleccione una escuela, luego Seleccione o Pinte al menos un bloque, las estadísticas de la escuela se mostrarán automáticamente en la sección de Estadísticas en el lado izquierdo de la página.

¿Puedo agregar una Escuela Secundaria a un Mapa de Distrito de Escuela Primaria?

Sí. Puede agregar cualquier escuela a cualquier mapa, sin embargo, el mapa seguirá reflejando solo los límites del distrito para el mapa base que seleccionó originalmente.

Solución de Problemas

Error al subir / capa en blanco

Compruebe que el archivo sea un GeoJSON válido y que esté por debajo de los límites de carga del navegador. Valide con geojson.io o conviértalo con ogr2ogr si es necesario.

Pintar no tuvo efecto

Confirme que la capa subida se superpone a los bloques censales y que se seleccionó la escuela destino correcta. Revise el texto de estado en Herramientas de Mapeo para ver errores.

Atajos

Espacio — Alternar Modo Pintura. Esc — Salir del Modo Selección. Los botones incluyen etiquetas ARIA; contacte al equipo si necesita soporte adicional de accesibilidad.
